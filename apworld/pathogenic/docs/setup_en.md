# Pathogenic Setup Guide

1. Own Pathogenic on Steam (the demo does not load mods) and subscribe to the
   Archipelago Shop mod on the Pathogenic Steam Workshop.
2. Start the game through Steam.
3. Open Settings > Archipelago, turn on "Enable Archipelago for new runs", enter the
   server as `ws://host:port`, your slot name, and the room password if any, then press Connect.
4. Start a new run. Buy or pick the pedestal marked ARCHIPELAGO to send a Shop Shipment.

The client log is shown on the same settings tab and stored in the game's user folder
under `archipelago_shop/client.log` (macOS:
`~/Library/Application Support/Godot/app_userdata/Pathogenic/archipelago_shop/client.log`).
Source and releases: https://github.com/ViMaSter/pathipelago
