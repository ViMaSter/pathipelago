# Pathogenic Demo Setup Guide

1. Build and install the private modded app with `build-install.sh` from the
   Local Archipelago Shop project.
2. Start the game with `launch-modded.command`.
3. Open Settings > Archipelago, enter the server as `ws://host:port`, your slot
   name, and the room password if any, then press Connect.
4. Buy the pedestal marked ARCHIPELAGO in any shop to send a Shop Shipment.

The client log is shown on the same settings tab and stored at
`~/Library/Application Support/Pathogenic Archipelago/archipelago_shop/client.log`.
